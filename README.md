# Student Internship Application Tracker

## Introduction

The Student Internship Application Tracker is a simple system
that helps students manage and track their internship applications.

## Features

- Add internship applications
- Track application status
- Store company information
- Track interview dates
- View application history

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
